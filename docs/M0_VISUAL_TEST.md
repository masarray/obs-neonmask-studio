# M0 Windows OBS visual test — actual output evidence

This is a test procedure, not a claim that the concept board is implemented. Use the
**Windows x64 preview artifact** from the *same successful workflow run* as the
fixture pack and build metadata. The generated fixture PNGs are original synthetic
test inputs, not screenshots of NeonMask output. This procedure supplies initial G4/G5
evidence; it does not certify performance, memory or eight-hour stability.

## Prepare

1. Use **OBS Studio 31.1.1 portable, Windows x64** for the pinned preview. Keep
   a backup of its OBS configuration and any older plugin. Fully exit OBS.
2. Download the successful run's artifact
   **obs-neonmask-v0.1.0-windows-x64-preview** from GitHub Actions.
   Extract the *outer artifact* first. Check the SHA256 file against the
   inner plugin ZIP using PowerShell:

   ~~~powershell
   Get-FileHash -Algorithm SHA256 .\obs-neonmask-v0.1.0-windows-x64-preview.zip
   Get-Content .\obs-neonmask-v0.1.0-windows-x64-preview.sha256
   ~~~

3. Extract **the inner plugin ZIP** to the portable OBS root, merging
   obs-plugins/64bit and data/obs-plugins. Do not point OBS at the outer ZIP.
   Do not replace a loaded DLL. Restart OBS. build-info.json is evidence
   beside the ZIP; it is not a plugin installation file.
4. Extract the separate **obs-neonmask-M0-visual-fixtures.zip**. Its PNGs and
   manifest.json are generated by tools/generate_visual_fixtures.py from
   the same repository checkout. The source command, for reproduction, is:

   ~~~powershell
   python tools/generate_visual_fixtures.py --out visual-fixtures --verify
   ~~~

## Ten-minute first capture

1. Create a new OBS scene collection. Set canvas and output to **1920×1080,
   60 fps**, SDR. Add opaque-bars.png as an Image Source and add the
   **NeonMask Studio — Facecam Mask & Border** *Effect Filter* on that source.
2. Check the OBS log for plugin load errors and the filter list for NeonMask.
   Start at its default. Record the **actual OBS output**, not a settings mockup.
3. Apply each of the four existing presets (Cyber Rounded, Reactor Ring,
   Emerald Hex, Ember Frame). Save a full-output capture on a dark Color Source
   background, then on a light background. Record the exact preset and
   rendering backend (OBS log).
4. Test all five shipped shapes: rounded rectangle, circle, ellipse, hexagon,
   diamond. Change scale, feather and border width. For a small-frame check,
   set the Image Source display size around 320×180, keeping the actual input
   dimensions recorded.
5. Repeat with alpha-ramp.png, soft-edge.png and transparent.png to inspect
   premultiplied-alpha edges and accidental opaque rectangles. Repeat with
   checkerboard-small.png and portrait-bars.png to expose aspect-ratio
   and corner issues. Compare dark/light backgrounds.
6. Put Crop/Pad, Color Correction and Chroma Key before and after NeonMask
   one at a time. Toggle the filter, change scene, duplicate/remove source,
   resize the source and restart OBS with the scene saved.
7. Test Static/Pulse/Flow, including zero speed. Record short clips for
   animation and any seam/phase jump. Do not infer eight-hour reliability
   from this short test.

## Current constraints

The preview currently implements five shapes, four border styles and four
presets, not all examples on the board. The halo can clip at source edges.
Current OpenGL/D3D11 CI smoke compiles effects but does not render final OBS
pixels. G6 timing, lifecycle stress and eight-hour soak remain pending.

No signing certificate or installer is required for this portable preview.
To roll back, close OBS, remove the matching NeonMask DLL and data directory,
restore any previous version, then restart OBS. Preserve scene backups.
